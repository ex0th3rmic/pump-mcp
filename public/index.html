Before you deploy this for others

  

    
The pump.fun Developer API Terms bind the key holder: keys are per organisation and may not be shared (6.4); you may not offer third parties programmatic access to API data (8.3b); cache API data for at most 24 hours (8.7); show “Data from pump.fun” to end users (10.3). Run this server for your own organisation’s agents and apps, behind your own MCP_BEARER_TOKEN. The on-chain, RPC and PumpPortal routes are not covered by those terms but PumpPortal has its own.
